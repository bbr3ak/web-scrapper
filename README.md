# Веб-скрапинг: hh.ru & Wildberries

> Учебный проект по дисциплине «Модели информационного взаимодействия» (МИРЭА).  
> Демонстрирует базовые навыки веб-скрапинга с помощью Selenium.

---

## Структура проекта

```
pr1/
├── hh.py       # Парсер вакансий с hh.ru
└── wb.py       # Парсер товаров с Wildberries
```

---

## Собираемые данные

### `hh.py` — вакансии с [hh.ru](https://hh.ru)

Открывает поиск вакансий по Москве, обходит первые 5 результатов и собирает:

| Поле | Описание |
|------|----------|
| Название вакансии | Заголовок вакансии |
| Зарплата | Вилка или фиксированная сумма |
| Краткое описание | Формат занятости |
| Ключевые навыки | Список требуемых навыков |
| Ссылка | URL вакансии |

Результат → `pr1hh1.xlsx`

> Примечание: скрипт `hh.py` может работать некоректоно, т.к. разработчики сайта часто меняют верстку.

---

### `wb.py` — товары с [Wildberries](https://wildberries.ru)

Открывает страницу поиска и собирает первые 5 товаров:

| Поле | Описание |
|------|----------|
| Бренд | Название бренда |
| Название | Наименование товара |
| Рейтинг | Оценка покупателей |
| Цена | Актуальная цена |
| Изображение | Ссылка на фото |

Результат → `pr1wb.xlsx`

## Установка и запуск

Проект использует [uv](https://docs.astral.sh/uv/) для управления зависимостями.

```bash
# Установить зависимости
uv sync

# Запустить парсер hh.ru
uv run hh.py

# Запустить парсер Wildberries
uv run wb.py
```

> **Требования:** установленный Google Chrome и совместимый [ChromeDriver](https://chromedriver.chromium.org/).

---

## Примечания

- Скрипты используют `time.sleep()` для ожидания загрузки — сайты рендерятся на стороне клиента.
- `wb.py` скрывает признаки автоматизации через `ChromeOptions`, так как Wildberries активнее детектирует ботов.
- После сбора данных браузер остаётся открытым до нажатия `Enter` — удобно для проверки результата.
